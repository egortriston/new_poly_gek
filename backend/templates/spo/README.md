# Печать СПО

Основа: `legacy_poly/commissions/pdf/spo_pdf.php`, исходные стили `styles_certification.css` и изображение бланка `assets/images/title.jpg`.

Адаптация: локальные ресурсы, mPDF 8, безопасная подстановка данных, сообщения при незаполненном титульном листе, печать выборки и год подписи из выбранного периода. Тексты распоряжения и служебной записки, состав таблиц и фиксированные подписанты сохранены. Новые формулировки и спорные изменения стандарта требуют уточнения пользователя.
