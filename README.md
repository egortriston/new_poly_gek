# Автоматизированная система поддержки образовательного процесса ИПМЭиТ

## Текущее состояние — версия 1.0

Подключены PHP API и реальный вход через существующую PostgreSQL `legacy_poly`. Используются серверные сессии и две роли: администратор (`admin`) и РОП (`rop`). Пароли — существующие пароли пользователей в БД. Фиксированный вход через браузер удалён.

Сначала запустить API, затем фронтенд:

```powershell
php -S 127.0.0.1:8081 -t backend/public backend/router.php
npm run dev
```

Перед первым запуском заполнить локальный `backend/config.local.php` по примеру. Он исключён из Git. Школы, преподаватели, направления, программы, дисциплины, внешние участники и карточки председателей подключены к PostgreSQL: доступны чтение, добавление, изменение и безопасное удаление. Комиссии, ООП, архив и печать ещё не переведены на сервер. Подробности, ограничения текущих этапов и проверки: [backend/README.md](backend/README.md). Ниже сохранены исторические заметки о разработке интерфейса; для входа и запуска действует инструкция выше.

## История прототипа

Локальное демо на React, TypeScript и Vite. Отдельный проект; сервер старого приложения и PostgreSQL не используются.

## Запуск

Требуется Node.js 22.14 или новее.

```powershell
npm ci
npm run dev
```

Откройте http://127.0.0.1:5174. Демо-вход: **admin / 12345678**. На странице входа есть кнопка заполнения этих данных. Регистрации нет.

## Что можно попробовать

- Поиск и фильтрация ГЭК по году, школе и заполнению.
- Создание комиссии, назначение председателя, секретаря и участников.
- Заполнение образования и сведений о председателе, выбор программ.
- Сохранение черновиков, предупреждение при уходе с несохранёнными изменениями.
- Формирование общей таблицы или документа отдельной комиссии, выгрузка CSV, печать / сохранение PDF через браузер.
- Просмотр справочника участников и связанных комиссий.
- Адаптивные экраны для компьютера и телефона.

Все люди и документы вымышлены. Сохранение работает в localStorage этого браузера; вход — имитация в sessionStorage. Реальных запросов в БД нет. Индикатор заполнения показывает наличие основных полей, а не официальное утверждение. Печатные формы демонстрационные, требуют сверки с утверждёнными шаблонами при подключении сервера.

## Новый маршрут (08.09.2026)

После входа открывается главная с пятью направлениями. Доступны ГЭК → список / формирование и печать, а также Исходные данные → Люди → три таблицы. Директора, направления, профили и дисциплины пока только обозначены в структуре. Формы в справочниках председателей различаются по сфере Образование / Бизнес; карточки этих справочников сохраняются отдельно от комиссий. Согласованные ограничения записаны в DESIGN-DECISIONS.md.

Проверка маршрута в отдельном тестовом браузере: `node verify-ui.mjs` (требуется установленный Microsoft Edge и запущенный `npm run dev`). Браузерный контекст изолирован, пользовательские данные не затрагивает.

## Архив и помощь

Архив поддерживает вложенные папки, загрузку нескольких файлов и перетаскивание, поиск в текущей папке, скачивание, переименование и удаление. При совпадении имён добавляется номер. Содержимое файлов хранится в IndexedDB только этого браузера, на сервер не передаётся. Очистка данных сайта удалит локальный архив.

На главной и в каждом основном разделе доступна контекстная помощь. Для ООП и аттестационных комиссий она явно отмечает пределы демо.

Актуальные браузерные проверки: `node verify-archive.mjs`, `node verify-selects.mjs`, `node verify-cards.mjs`. Нужны Microsoft Edge и запущенный сервер разработки. Сценарии запускаются в изолированном браузерном контексте.

## Дополнительные справочники

В разделе «Люди» доступны преподаватели, в «Структуре университета» — высшие школы с директором и должностью, в «Образовании» — направления, программы и дисциплины. Есть поиск, фильтры, добавление, редактирование и удаление с проверкой связей внутри каталога. Направление связано с несколькими программами. Записи сохраняются в localStorage отдельно от прежних моков комиссий.

Проверка: `node verify-catalog.mjs`.
