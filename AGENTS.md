# Правила интерфейса и печати

- Для таблиц с большим числом столбцов используйте общий `src/components/HorizontalTableScroll.tsx`: горизонтальная прокрутка внутри таблицы, тонкий зелёный ползунок со стрелками, без рамки вокруг активного ползунка. Не растягивайте страницу по ширине.
- Печатные формы воспроизводят исходные PHP-шаблоны через mPDF. Унифицированный текст, поля, подписи и формат нельзя произвольно менять. Спорные изменения согласовывайте с Егором.
- Изменения структуры существующей БД допускаются только после предварительного явного согласования с Егором. До выполнения описать конкретные изменения, зачем они нужны и как повлияют на данные и приложение; дождаться разрешения. Общая постановка задачи не считается разрешением на изменение схемы. Прямые исправления и массовые преобразования рабочих данных также предварительно согласовывать.
- Не заменять обусловленные требованиями константы без уточнения.
